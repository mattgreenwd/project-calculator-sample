# Website Project Cost Calculator

A lightweight Vite + vanilla JavaScript demo that estimates website project costs. Built for a tutorial on deploying a static web app to Webflow Cloud.

## Features

- Page count slider (1–20) at $250 per page
- Template ($500) or custom ($1,500) design selection
- Optional SEO setup (+$500) and CMS integration (+$750)
- Live total with a cost breakdown
- Responsive two-column layout (stacks on mobile)

## Requirements

- Node.js 22 or later (recommended for Webflow Cloud)

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173/`).

## Production build

```bash
npm run build
```

Static files are written to the `dist/` directory. Preview the production build locally with:

```bash
npm run preview
```

## Deploying to Webflow Cloud

1. Push this repository to GitHub.
2. In your Webflow dashboard, create a new app / project.
3. Connect the GitHub repository and deploy.

## Note

Prices are illustrative for demonstration only and are not a formal quote.
